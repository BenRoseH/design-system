# Mon design system

## Stack
- React + TypeScript + Vite
- Base UI (@base-ui/react) pour les composants headless
- CSS vanilla avec custom properties pour le style

## Règles
- Jamais d'inline styles
- Toujours utiliser les tokens définis dans src/tokens/tokens.css
- Un fichier CSS par composant

## Tokens principaux
- --color-primary: #FF6B00
- --color-text: #1A1A1A
- --color-background: #FFFFFF
- --radius-md: 8px
- --spacing-base: 4px
